# 10 · Glosario y referencias

## Glosario mínimo

| Término | En este proyecto significa… |
|---|---|
| Doble rendija | Barrera con dos aberturas estrechas y cercanas; experiencia de Young |
| Interferencia | Suma de amplitudes de dos caminos: donde se refuerzan hay franja, donde se cancelan, no |
| Difracción | Dispersión de una onda al pasar por una abertura comparable a λ |
| Envolvente | Curva ancha (una rendija) que modula las franjas finas (dos rendijas) |
| \|ψ\|² | Densidad de probabilidad de detectar la partícula en cada posición |
| *Which-path* | Información de por cuál rendija pasó la partícula; al obtenerla, la interferencia desaparece |
| Fraunhofer | Aproximación de campo lejano usada por el modelo (frentes planos, ángulos pequeños) |
| Muestreo por rechazo | Generar puntos al azar aceptándolos con probabilidad I(x) |
| λ de de Broglie | λ = h/p: toda partícula con momento `p` tiene longitud de onda asociada |
| *Bin* | Cajita del histograma que cuenta impactos por intervalo de posición |
